InsideMeeting 使用说明

内部会议系统 · 不限时长 · 自动生成会议纪要

这是我们自己搭的内部会议系统，替代腾讯会议 / Zoom。和它们比，有三点不一样：

  • 不限时长。没有 40 分钟踢人，没有人数套餐。
  • 自动出会议纪要。会议进行中右侧就能看到实时纪要；会后系统会生成完整的逐字稿和纪要，而且会写清楚每条结论是谁说的。
  • 录像存在公司自己的机器上，不上传到任何第三方云盘。
开始之前，请先把这两项信息填上（管理员会告诉你）

一、第一次使用（只需做一次）

因为这套系统只对公司内部开放，不在公网上，所以你需要先装一个叫 Tailscale 的小软件。它的作用是把大家的电脑连进同一个内部网络——装好之后你平时上网完全不受影响，可以一直开着。

第 1 步：下载安装 Tailscale

打开 https://tailscale.com/download，网站会自动识别你的设备，点大按钮下载即可。也可以按下表操作：

你的设备怎么装
Windows 电脑访问上面的网址，下载 .msi 文件，双击一路点「下一步」。装完右下角任务栏会出现一个小图标。
Mac 电脑访问上面的网址下载，或直接在 App Store 搜索「Tailscale」安装。装完右上角菜单栏会出现一个小图标。
iPhone / iPad在 App Store 搜索「Tailscale」，认准蓝色的字母 logo，直接安装。
安卓手机在应用商店搜索「Tailscale」；搜不到就用上面的网址下载安装包。

第 2 步：登录

打开 Tailscale，它会让你选择登录方式（Google、微软账号等）。请使用管理员告诉你的那种登录方式，用错账号会连不进来。

登录后可能会显示「等待管理员批准」。这是正常的，通知管理员一声，他点一下就通过了。

第 3 步：确认装好了

怎么判断装好了没有

看 Tailscale 的图标或界面上是否显示 Connected（已连接）。Windows 在右下角任务栏，Mac 在右上角菜单栏，手机上打开 App 就能看到一个开关，确保它是打开的。

重要：Tailscale 要保持开启

关掉 Tailscale 就进不了会议了。它很省电，建议一直开着，开机自动启动。如果哪天突然打不开会议网址，第一件事就是检查它是不是被关掉了。

第 4 步：打开会议网址，存成书签

用 Chrome 或 Edge 浏览器打开本文开头填的那个会议网址（Safari 也能用，但建议优先用 Chrome）。能看到入会页面就说明一切正常。把它加到收藏夹，以后开会直接点。

二、怎么进入一场会议

打开会议网址后，你会看到一个页面，左边是你的摄像头预览，右边要填两项：

你的姓名请填真实姓名。这个名字会直接出现在会议纪要里，比如「@张三 确认接口周三交付」。填「abc」或者「测试」，纪要里就会出现「@abc 说……」，别人看不懂。
房间号由会议发起人指定，比如 weekly、产品评审。填一样的房间号就会进同一个会，没有别的加入方式。

下面还可以先关掉摄像头或麦克风再进去，以及在「设备选择」里挑用哪个麦克风、哪个摄像头。填好点加入会议。

怎么邀请别人

进会后点右上角的复制入会链接，把链接发给对方即可，对方打开就是同一个房间。或者直接口头告诉他房间号。

四、会议中的各项功能

麦克风和摄像头

底部前两个按钮，点一下开、再点一下关。按钮变红色代表已经关闭。别人的画面右下角会显示一个静音标记，你能看出谁静音了。

共享屏幕

点底部的共享屏幕，浏览器会弹窗让你选择共享整个屏幕、某个窗口还是某个浏览器标签页。

  • 演示 PPT、演示软件 → 选「整个屏幕」或「窗口」。
  • 放视频、需要对方听到声音 → 选「标签页」，并勾选左下角的「共享标签页音频」，否则对方只能看到画面听不到声音。

一旦有人开始共享，所有人的画面会自动切到共享内容，不需要任何人手动操作。共享结束后自动切回。

切换画面布局

自动（默认）有人共享屏幕就显示共享内容，没人共享就平铺显示所有人。日常用这个就行。
画廊永远平铺显示所有人，哪怕有人正在共享。适合想看清每个人表情的场合。
演讲者大画面自动跟着当前说话的人切换，其他人缩在下方一条。适合有人长时间讲的会。

双击任何一个人的画面可以把他固定在大画面上，再双击一次取消。固定之后就不再自动跟随了。

举手

点底部的举手，你的画面上会出现一个举手标记，所有人都能看到。发言完记得再点一次放下。

文字聊天

右侧「聊天」标签页。发链接、发编号这类不方便念的内容用它最方便。聊天记录会一并存进会议记录。

请别人静音

右侧「成员」标签页，每个人后面有「请他静音」。这是发一个提醒给对方，不是强制——对方会收到提示，由他自己决定要不要静音。用来提醒忘记静音的同事很方便。

五、录制与会议纪要

开始录制

重要：录制是全员一起的

任何人点开始录制，房间里所有人都会同时开始录各自的声音。这是故意这么设计的——每个人的声音单独录一条，系统才知道每句话是谁说的。

反过来说，谁没在录，纪要里就没有谁。所以录制期间请不要中途退出再进来。

录制开始后，顶部会出现红色的「● 录制中」。录制没有时长限制，开多久录多久，文件每 60 分钟自动分成一段，你不需要做任何操作。

会议中看实时纪要

右侧「实时纪要」标签页，默认就是开着的。你会看到：

  • 上半部分：每分钟自动刷新一次的摘要，分成「目前在聊什么 / 已经明确的 / 出现的待办 / 分歧与待确认」四块。
  • 下半部分：展开后是滚动的逐字记录，大约延迟 20 秒。
中途加入会议不用问「刚才说到哪了」

你一进来，右侧就会自动显示这场会前面的全部内容和最新摘要，自己看一眼就跟上了。

实时纪要是边开会边转文字生成的，速度优先，偶尔会有识别错的地方（尤其是人名和专业术语），参考着看就行。会后那份更准。

会后拿完整纪要

会议结束后，在会议网址的会议记录页面找到这场会，点生成逐字稿与会议纪要。一场一小时的会大约几分钟出结果，包括：

  • 会议纪要：关键结论、分议题记录、待办表格，每条都标注了是谁说的。可以下载或一键复制全文。
  • 逐字稿：带时间戳的完整对话记录。
  • 待办清单：事项、负责人、截止时间。
  • 发言统计：每个人说了多久、多少轮。
  • 录制文件：可以在线播放或下载。

如果发现纪要里某个人的名字写错了（通常是因为他入会时名字填错），在「录制文件」标签页点「改名」改掉，再点「仅重写纪要」即可，不需要重新处理一遍。

手机浏览器直接打开同一个会议网址就行，前提是手机上也装了 Tailscale 并保持开启。

手机上的按钮只显示图标不显示文字，实时纪要和聊天收在底部，点工具栏的笔记图标弹出来。

手机参会最重要的一条：别锁屏、别切后台

手机一旦锁屏或者切到别的 App，系统会暂停录音，你这段时间说的话不会进纪要。如果你在会上要发言，请让浏览器一直停在前台。只是旁听不发言的话没关系。

七、六条重要提醒

  1. 每个人用自己的设备入会。 两个人挤在一台电脑前用同一个麦克风，系统会把你俩认成同一个人，纪要里分不开。人在一个会议室也请各开各的设备（记得戴耳机）。
  2. 戴耳机。 不戴耳机时，你的音箱放出来的别人的声音会被你的麦克风重新收进去，造成回声，也会污染纪要。
  3. 姓名填真名。 纪要里的 @某某 直接取自你填的名字。
  4. Tailscale 保持开启。 关了就连不上。
  5. 电脑端优先用 Chrome 或 Edge。 其它浏览器可能有功能缺失。
  6. 静音期间说的话不会被记录。 这是正常的——要发言记得先取消静音。
