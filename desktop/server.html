还差这几步

  1. 打开管理后台，填入转写和纪要的 API 密钥
    不填也能开会，只是不会生成会议纪要。
  2. 在管理后台把三道口令设上：入会口令、查看会议记录的口令、管理口令
    尤其第二个——不设的话，能连进来的人就能翻到全部历史会议的录音和全文。
  3. 让这台电脑别休眠
    睡着了所有人立刻断会。macOS：sudo pmset -a sleep 0；Windows 在电源设置里把睡眠改成「从不」。
  4. 同事首次打开会看到证书不安全的提示
    自签证书的正常现象，点「高级 → 继续前往」即可，每台设备点一次。
